# WorkBuddy Connect Community 0.1.26

WorkBuddy Connect Community 补齐 DSH 0.2.1 和 0.2.2 两个系列的发布候选版。每个系列支持 rc.1 至 rc.5。

- 新增 DSH 0.2.1-rc.1、0.2.1-rc.4、0.2.2-rc.2 和 0.2.2-rc.4 的精确版本声明。
- 两个系列的 10 个 Web 宿主通过安装、加载、配置卡片和卸载检查。Desktop 验证覆盖 Windows x64、Apple Silicon 的 0.2.2-rc.5 正式版，以及 Intel Mac 的 0.2.1-rc.4 开发版打包 Host。
- 保留旧宿主的账号范围请求头兼容处理。真实模型调用需要相应的 WorkBuddy 登录和可用的上游服务。

[发行版本与安装方式](https://github.com/tangyixiao/dsh-workbuddy-connect-community/releases/tag/v0.1.26)

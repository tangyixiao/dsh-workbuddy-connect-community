# WorkBuddy Connect Community 0.1.25

WorkBuddy 和 WorkBuddy AI 提供方可以在 DSH 0.2.2-rc.5 中注册。

- 将 rc.5 加入宿主和宿主依赖声明，保留账号范围检查以及既有模型设置。
- DSH 兼容范围为 `0.2.1-rc.2 || 0.2.1-rc.3 || 0.2.1-rc.5 || 0.2.2-rc.1 || 0.2.2-rc.3 || 0.2.2-rc.5`。
- 在 DSH rc.5 Web 宿主检查了发布包的安装和只读入口。真实模型调用需要相应客户端账号和可用的上游服务。
